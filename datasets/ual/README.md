### husky_benches

Clearpath Husky A200 with an Ouster LiDAR, outdoors, with a map of the place
and ground truth, for LiDAR localization tests where the initial pose is wrong
and the scene only weakly constrains it. See `husky_benches/dataset.yaml`.
